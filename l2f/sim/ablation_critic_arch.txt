# Critic architecture between shared and split (2026-11-26), actor OS-NMF-PGA. The shared 4-head
# critic's group values collapse (0.93-1.00 correlated at 2M) although the groups' rewards are
# nearly uncorrelated (-0.08..+0.16): the targets bootstrap from the same collapsed network, so the
# collapse feeds itself. Separate critics per group fix it but have 3.9x the parameters (26,116 vs
# 6,724). Is it the sharing or the size? Arms: the shared critic at 64; a shared critic widened to
# 142 (25,990 parameters, the split critic's size: capacity control); towers (shared first layer,
# per-group second layer and output, 19,204 parameters). Baseline to beat: td3 = variant E.

# 2026-11-27: target-spread normalization (--critic-norm-by target). --critic-norm divided each group's
# TD error by the error's own running RMS, so every group's loss stayed ~1 however well it fit (size-
# blind, as PGA). Here the error is divided by the running std of the group's TD targets (PopArt-like):
# common units, while a badly fitted group still pulls harder (100k-step check: losses 0.012-0.097,
# critic gradient norms within ~10x). Groups only (no --total).

arm  moo4osnmfpga_cnt_ccagrad       --moo parts --parts 4 --agg osnmf_pga --critic-agg cagrad --critic-norm --critic-norm-by target
arm  moo4osnmfpga_cnt_cupgrad       --moo parts --parts 4 --agg osnmf_pga --critic-agg upgrad --critic-norm --critic-norm-by target
# 2026-11-27 code review: with --total 1 the critic loss (sum_k e_k)^2 + sum_k e_k^2 gives every head the
# gradient e_k + sum_j e_j, so the total error (dominated by safety) is broadcast to all heads: a
# common-mode force that, through a shared trunk, can drive the heads together (every collapsed shared
# arm had --total 1; every no-total arm stayed distinct). The plain shared critic with independent
# per-head losses only (no --total, no aggregator, no normalisation) had never been run; nor the split
# critic without the total term.
arm  moo4osnmfpga_nt                --moo parts --parts 4 --agg osnmf_pga
arm  moo4osnmfpga_split_nt          --moo parts --parts 4 --agg osnmf_pga --split-critic
# 2026-11-27 2x2 (research report "Shared critic collapse and reward design"): (a) per-objective
# termination bias - time, precision, efficiency are pure costs and the whole crash penalty sat in
# safety, so three groups gain from crashing; --crash-split shares the terminal reward in proportion
# to each group's typical future cost (critic value means: time ~8, precision ~90, efficiency ~70,
# safety's dense part ~10), scalar reward unchanged; (b) the shared critic had 39% of its layer-2
# FAST_TANH units dead and feature srank 11/64 at 2M: --critic-layer-norm puts LayerNorm before each
# hidden activation. Reference: moo4osnmfpga (shared, total term, 4.5% crashes).
arm  moo4osnmfpga_csplit            --moo parts --parts 4 --total 1 --agg osnmf_pga --crash-split time=18,precision=202,efficiency=157,safety=23
arm  moo4osnmfpga_ln                --moo parts --parts 4 --total 1 --agg osnmf_pga --critic-layer-norm
arm  moo4osnmfpga_ln_csplit         --moo parts --parts 4 --total 1 --agg osnmf_pga --critic-layer-norm --crash-split time=18,precision=202,efficiency=157,safety=23
