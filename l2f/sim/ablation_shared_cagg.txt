# step 1b (2026-11-25): the critic aggregators failed (35-95% crashes) though --critic-agg sum flies
# like the old shared critic (no bug). The groups' critic gradients differ 100-3000x in size (safety
# holds the crash penalty) and PGA weights by direction only. --norm makes each head learn its group
# value / s_k (s_k = RMS reward / (1 - gamma), measured at critic start), so the 4 group losses are
# about size 1; no --total, so no real-unit total objective brings the size gap back.
arm  moo4svdpga_norm_csum           --moo parts --parts 4 --norm --agg svd_pga --critic-agg sum
arm  moo4svdpga_norm_cupgrad        --moo parts --parts 4 --norm --agg svd_pga --critic-agg upgrad

arm  moo4svdpga_norm_cosnmfpga      --moo parts --parts 4 --norm --agg svd_pga --critic-agg osnmf_pga

# step 1c (2026-11-25): --norm (scales fixed at critic start) left the critic gradients 1e5 apart and
# norm + sum crashed 55%. --critic-norm divides each group's TD error by its running RMS every update:
# losses about 1 and gradient norms within ~3x (100k-step smoke run). The clean test: equal sizes, then aggregate.
arm  moo4svdpga_cn_csum             --moo parts --parts 4 --agg svd_pga --critic-agg sum --critic-norm
